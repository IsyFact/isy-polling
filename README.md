# isy-polling

Diese Bibliothek bietet Funktionen Polling-Operationen mit mehreren Servern.

## Features

In Geschäftsanwendungen müssen manchmal Polling-basierte Schnittstellen angesprochen werden.
Aus Gründen der Ausfallsicherheit soll die Abholung der Daten von mehreren Instanzen einer
Anwendung durchgeführt werden. Diese Instanzen müssen synchronisiert werden,
sodass Nachrichten nicht mehrfach verarbeitet werden. isy-polling bietet mit den Klassen

* PollingVerwalter
* PollingCluster

Unterstützung. Zusätzlich existieren Methoden und Klassen zur Konfiguration und Einbindung
in Spring-Anwendungen.
